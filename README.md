# Certificate Vault 🏅

A self-contained, offline-ready certificate dashboard built with vanilla HTML, CSS and JavaScript.

## Features
- View certificates inline without leaving the page
- Google Drive button on every certificate for sharing and downloading
- Search and filter by category
- Works fully offline from a pendrive or laptop
- No frameworks, no dependencies, no internet required

## How to Use
1. Clone or download this repository
2. Put your certificate PDFs inside the `files/` folder
3. Edit the `certificates` list in `certificates.html` with your file names and Google Drive links
4. Run a local server: `python -m http.server 8000`
5. Open `http://localhost:8000` in your browser
