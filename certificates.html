How to set this up — read once, then delete this banner

Folder structure on your pendrive / laptop: Keep this certificates.html file and a folder called files/ together in the same place. Put every PDF or image inside files/. Example: files/science_olympiad_2024.pdf

Editing the list: Open this file in Notepad (Windows) or TextEdit (Mac). Find const certificates = [. For each certificate fill in localFile (the filename inside files/) and driveLink (right-click file in Google Drive → Share → Anyone with the link → Copy link).

When done: delete this entire <div class="setup-banner"> block from the file.
